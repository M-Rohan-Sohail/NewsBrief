1.1 The Fundamental Structural Problem

Currently, backend/run_pipeline.py executes a linear loop per registered user: 

For each User:
    For each Search Query (5-8 queries):
        Serper.dev News Search (3 links)
        Jina Reader Scrape (3 pages)
    sentence-transformers Deduplication
    Groq LLM Thematic Clustering
    Groq LLM Card Generation
    Groq LLM Super Summary Generation
    Save to DB & Send Push

Failure Modes:

  • Quadratic Scaling & Rate Limits: 1,000 users with overlapping interests trigger 6,000 Serper searches, 18,000 Jina scrapes, and 6,000 Groq cluster calls. Serper and Jina API keys will be throttled within minutes, and monthly costs will exceed $1,500.
  • SEO Spam & PR Farm Poisoning: Serper returns syndicated PR newswires and content-farm blog posts, degrading summary quality for technical founders.
  • Single Point of Failure Delivery: Only delivering via Mobile Push means if an iOS or Android user denies notification permissions, engagement drops to zero.

1.2 The Two-Stage Decoupled World-State Architecture

We decouple the system into two distinct operational stages running on separate schedules: 

STAGE 1: GLOBAL WORLD-STATE INGESTION & CLUSTERING (Daily at 03:00 UTC)
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ Sources: Hacker News (Firebase), GitHub Trending, arXiv Preprints, Curated Tech RSS    │
│ Pipeline: Ingest All Raw Articles (Pool: ~500) -> Semantic Dedup -> Groq Clustering   │
│ Output: 50–80 Canonical NewsClusters with 384-dim Centroid Embeddings in PostgreSQL    │
│ Pre-generation: Base Cards & Top-10 In-depth Research Deep Dives generated ONCE.       │
└────────────────────────────────────────────────────────────────────────────────────────┘

STAGE 2: PERSONALIZED USER DELIVERY ENGINE (Daily at 06:30 Local User Time)
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 1. Vector Match: User Preference Embedding <=> Cluster Embeddings (via pgvector)       │
│ 2. Select: Top 5-7 highest similarity clusters for the individual user                 │
│ 3. Synthesize: User-tailored Super Summary in user's configured tone bucket (1.2s LLM) │
│ 4. Dispatch: Multi-channel delivery to Email Digest, Mobile Push, Audio TTS, Slack Bot │
└────────────────────────────────────────────────────────────────────────────────────────┘

Exact Implementation Instructions
  • HN Module (hn.py): Call https://hacker-news.firebaseio.com/v0/topstories.json. Fetch item details for the top 30 IDs from https://hacker-news.firebaseio.com/v0/item/{id}.json. Filter for stories with score >= 30. Extract URL and title; if story is a text post (Ask HN / Show HN), use item.text as content. If external link, call Jina Reader with 5s timeout.
  • GitHub Module (github.py): Call GitHub Search API https://api.github.com/search/repositories?q=created:>{7_days_ago}+stars:>100&sort=stars&order=desc. Map top 15 repositories to RawArticle with content set to repo description, primary language, star count, and README.md first 800 characters.
  • arXiv Module (arxiv.py): Call arXiv API http://export.arxiv.org/api/query?search_query=cat:cs.AI+OR+cat:cs.LG+OR+cat:cs.CL&start=0&max_results=25&sortBy=submittedDate&sortOrder=descending. Parse XML using xml.etree.ElementTree. Extract title, abstract summary, published date, PDF link, and authors.
  • RSS Module (rss.py): Maintain a static list of 20 verified high-signal RSS URLs (e.g. Stratechery, SemiAnalysis, Latent Space, Pragmatic Engineer, Simon Willison). Use feedparser.parse(url) with an HTTP ETag / If-Modified-Since cache header. Extract articles published in the last 36 hours.

Checkpoint 18: Stage 1 Global World-State Pipeline Backend Pipeline
Objective & Scope

Build the standalone, user-independent Stage 1 pipeline script. Ingests all sources, deduplicates, clusters, generates centroid embeddings, and pre-generates base Cards and Deep Dives once into the database.

Files to Create / Modify
  • [NEW] backend/pipeline_stage1.py — Main orchestrator for Stage 1 batch.
  • [MODIFY] backend/clustering.py — Add centroid embedding computation (mean pooling + normalization).
  • [MODIFY] backend/generation.py — Add batch card generation and priority Deep Dive generation.
  • [NEW] backend/tests/test_pipeline_stage1.py — End-to-end stage 1 test with mock sources.
Step-by-Step Execution Flow
  1. Aggregation: Concurrently call fetch_hacker_news(), fetch_github_trending(), fetch_arxiv_papers(), fetch_rss_feeds(). Combine into List[RawArticle] (~400–600 items).
  2. Deduplication: Embed f"{art.title}. {art.content[:400]}" via sentence-transformers (all-MiniLM-L6-v2). Compute cosine distance matrix. Retain only articles with similarity < 0.82 to any higher-ranked article.
  3. Clustering: Pass surviving article titles + snippets to Groq (qwen/qwen3.8-27b). Prompt outputs 40–70 clusters with canonical titles, matched tags, and article index mappings.
  4. Centroid Embedding Calculation: 
    def compute_centroid(article_embeddings: np.ndarray) -> List[float]:
    centroid = np.mean(article_embeddings, axis=0)
    norm = np.linalg.norm(centroid)
    if norm > 0:
        centroid = centroid / norm
    return centroid.tolist()
  5. Pre-generation:
    • For each cluster, generate base Card for high_signal and technical_deep tone.
    • Select the top 10 clusters (ranked by source count + score) and pre-generate the structured 4-section DeepDive markdown.
  6. Database Upsert: Save all NewsCluster, Card, and DeepDive records linked to batch_date = today in a single transaction.

def match_clusters_for_user(db: Session, user_id: UUID, limit: int = 6) -> List[models.NewsCluster]:
    pref = db.query(models.UserPreference).filter(models.UserPreference.user_id == user_id).first()
    
    # If user has no embedding, compute and save it once
    if pref.preference_embedding is None:
        text = f"{pref.raw_paragraph} {' '.join(pref.thematic_tags or [])} {' '.join(pref.search_queries or [])}"
        pref.preference_embedding = get_embedder().encode(text).tolist()
        db.commit()
        
    today = datetime.now(timezone.utc).date()
    # High-speed pgvector cosine distance query
    matched_clusters = db.query(models.NewsCluster).filter(
        models.NewsCluster.batch_date == today
    ).order_by(
        models.NewsCluster.embedding.cosine_distance(pref.preference_embedding)
    ).limit(limit).all()
    
    return matched_clusters
